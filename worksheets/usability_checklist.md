# Lab 7 — Usability checklist (tick before your user test)

- [ ] The first screen says what the assistant can do, with example questions
- [ ] Empty or too-long input shows a friendly message (not a crash)
- [ ] While waiting, the user sees "Thinking…"
- [ ] Every answer from documents shows its sources
- [ ] "I don't know" answers tell the user who can help (escalation)
- [ ] If the backend is down, the page says so clearly
- [ ] Each answer has 👍 / 👎, and clicking gives a "thanks" message
- [ ] The page says it is an AI assistant
- [ ] Text is readable (size, contrast); buttons have clear labels
- [ ] Works on a phone-width window
